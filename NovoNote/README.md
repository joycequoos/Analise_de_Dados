## Sobre o Notebook do Jupyter

Um notebook do Jupyter é um documento interativo que combina código executável, texto formatado e elementos de mídia, como imagens e gráficos, tudo em um único ambiente. Ele permite a criação e o compartilhamento de análises de dados, exploração de dados, modelagem estatística, visualizações interativas e até mesmo o desenvolvimento de aplicações completas.

O formato do notebook é baseado em células, unidades individuais de conteúdo, que podem conter diferentes tipos de material:

- **Células de código** — nelas você escreve e executa código em linguagens suportadas, como Python, R ou Julia. O código roda no kernel do Jupyter em tempo real, e os resultados são exibidos logo abaixo da célula, permitindo uma abordagem iterativa de desenvolvimento.
- **Células de texto (Markdown)** — usam a sintaxe Markdown para formatar o texto, permitindo adicionar títulos, listas, links, imagens, fórmulas matemáticas e outros elementos, possibilitando criar explicações, documentação e relatórios dentro do mesmo ambiente do código.
- **Células de saída** — quando as células de código são executadas, produzem resultados exibidos logo abaixo, podendo ser texto formatado, tabelas, gráficos ou qualquer outra saída gerada pelo código.

A grande vantagem dos notebooks do Jupyter é permitir a criação de documentos interativos e autocontidos — especialmente útil na análise de dados, pois é possível incluir visualizações, explicar o raciocínio por trás das análises e compartilhar os resultados de forma clara e compreensível.

## Passo a Passo para Criar um Novo Notebook

### 1. Criar uma pasta para o novo notebook

Crie uma pasta no seu computador para armazenar o novo Jupyter Notebook.

![Criar Notebook](01_Criar_Notebook.GIF)

### 2. Acessar o Prompt de Comando

Abra o Prompt de Comando (ou Anaconda Prompt) no seu computador.

![Prompt](02_Prompt.GIF)

### 3. Localizar o diretório no Prompt de Comando

Navegue até a pasta criada anteriormente, utilizando o Prompt de Comando.

![Acessar Diretório](03_Acessar_Diretorio.GIF)

### 4. Incluir o comando "Jupyter Notebook"

No diretório correto, digite o comando `jupyter notebook`.

![Jupyter Notebook](04_Jupyter_Notebook.GIF)

### 5. Abertura do Jupyter Notebook

Após incluir o comando, o Jupyter Notebook é aberto automaticamente no navegador, já dentro da pasta escolhida.

![Abertura Jupyter](05_Abertura_Jupyter.GIF)

Pronto — seu novo notebook está criado!
