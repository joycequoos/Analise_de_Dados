## About Jupyter Notebook

A Jupyter notebook is an interactive document that combines executable code, formatted text, and media elements like images and charts, all within a single environment. It enables the creation and sharing of data analyses, data exploration, statistical modeling, interactive visualizations, and even the development of complete applications.

The notebook format is based on cells — individual units of content — which can hold different types of material:

- **Code cells** — where you write and run code in supported languages, such as Python, R, or Julia. The code runs in the Jupyter kernel in real time, and results are displayed right below the cell, enabling an iterative development approach.
- **Text cells (Markdown)** — use Markdown syntax to format text, allowing you to add headings, lists, links, images, mathematical formulas, and other elements, making it possible to create explanations, documentation, and reports within the same environment as the code.
- **Output cells** — when code cells are run, they produce results displayed right below, which can be formatted text, tables, charts, or any other output generated by the code.

The big advantage of Jupyter notebooks is that they allow the creation of interactive, self-contained documents — especially useful in data analysis, since you can include visualizations, explain the reasoning behind the analyses, and share results in a clear and understandable way.

## Step-by-Step to Create a New Notebook

### 1. Create a folder for the new notebook

Create a folder on your computer to store the new Jupyter Notebook.

![Criar Notebook](01_Criar_Notebook.GIF)

### 2. Open the Command Prompt

Open the Command Prompt (or Anaconda Prompt) on your computer.

![Prompt](02_Prompt.GIF)

### 3. Locate the directory in the Command Prompt

Navigate to the folder you created earlier, using the Command Prompt.

![Acessar Diretório](03_Acessar_Diretorio.GIF)

### 4. Run the "Jupyter Notebook" command

In the correct directory, type the command `jupyter notebook`.

![Jupyter Notebook](04_Jupyter_Notebook.GIF)

### 5. Jupyter Notebook opens

After running the command, Jupyter Notebook opens automatically in your browser, already inside the chosen folder.

![Abertura Jupyter](05_Abertura_Jupyter.GIF)

That's it — your new notebook is created!
